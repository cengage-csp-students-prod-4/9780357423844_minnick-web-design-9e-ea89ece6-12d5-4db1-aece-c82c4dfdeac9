Hexadecimals use a base-16 system that uses the numbers 0-9 and letters A-F to specify red, green, and blue values. RBG codes use intensity values on a scale of 0 to 255 to combine the colors red, green, and blue to define colors. HSL defines colors by using the color's hue location on a 360 degree color wheel, saturation percentage, and black or white intensity(lightness).

Preferred color code format: I originally believed that RGB was the best way to format color codes, but I now understand that HSL is superior due to its easy to read layout which allows for swift modification when changing color codes.

HWB summary: HWB stands for hue, whiteness, and blackness. This specifies the base color hue and then describes how much white or black is mixed together to adjust the color to find a specific shade.

CMYK summary: CMYK stands for cyan, magenta, yellow, and key(black). It is a subtractive color model, meaning it uses different colors to absorb certain light wavelengths to better reflect other colors off of a white background. This type of color scheme is commonly used for physical printing.
