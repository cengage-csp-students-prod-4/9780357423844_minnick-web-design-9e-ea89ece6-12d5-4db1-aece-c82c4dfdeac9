Working with Positions

Sticky

This is an example of an element with a sticky position. Its position is based on the user's scroll position.

Sticky position will anchor an element fixed to a position while scrolling on a page. When it reaches a specific threshold, the element will stick to that point and remain onscreen after you scroll past.

Relative

This is an example of an element with a relative position. It can move around a little, depending on the viewport, but it is in a position relative to itself.

The relative position anchors the element near its original position and shifts it in relation to the original position.

Fixed

This is an example of an element with a fixed position. Its position is relative to the viewport.

The fixed position anchors the element locked at the defined position on screen at all times and ensures it remains there even while scrolling.

Absolute

This is an example of an element with an absolute position. It is similar to the fixed position; however, it is positioned relative to the closest parent element.

The absolute position anchors the element at the defined position relative to the position of the nearest element
