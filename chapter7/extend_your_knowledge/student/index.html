To create my columns, I used the multi-column layout to create 3 equally sized columns that automatically form themselves around the text within. I chose to wrap the code in the class selector ".columns" for ease of reference. inside the class selector, I simply defined the number of columns to be 3 and set the height and width to auto so that it would fit itself arounf the text in the paragraphs. I then applied the class to the article element containing the paragraphs so that it would read the contents as one continuous text line and shape the columns based on the text. Info Source
